Conectar este dispositivo

Para que el panel pueda guardar productos necesita una llave de GitHub. Se hace una sola vez en cada celular o computadora.

  1. Abre esta página de GitHub (con tu cuenta milanesproductions-lgtm).
  2. En Token name escribe Panel Mila.Desk. En Expiration elige la fecha más lejana que te deje.
  3. En Repository access elige Only select repositories y marca solo mila-desk-links.
  4. En Permissions → Repository permissions, busca Contents y elige Read and write. Nada más.
  5. Toca Generate token, cópialo y pégalo aquí abajo.

Se guarda solo en este dispositivo. No la compartas con nadie.
